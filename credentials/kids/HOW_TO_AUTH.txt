Kids channel YouTube (English only). Do this on a computer YOU own.

GitHub runs the factory. Do not save tokens on a borrowed PC.

1. Google Cloud → YouTube Data API v3 → OAuth Desktop client
2. python -m pipeline.oauth_bootstrap
3. Repo Settings → Secrets → Actions:
   YOUTUBE_CLIENT_SECRET_JSON
   YOUTUBE_REFRESH_TOKEN
4. Actions → Daily kids Short → Run workflow

Full steps: docs/GITHUB.md
Do NOT use Ghost of Sparta / gaming OAuth files.
