# Kids / YouTube policy notes

- Mark uploads **Made for Kids** when the content is directed at children.
- No call-to-action that collects personal data from kids.
- No scary thumbnails, blood, injury porn, or “gross-out” anatomy for young bands.
- Ages 11–16 may use clearer diagrams still without graphic injury.
- Keep this channel separate from adult/gaming brands.
- Review each script with the age-band `forbidden` list in `config/age_bands.json`.
